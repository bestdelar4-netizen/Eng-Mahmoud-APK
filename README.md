# Eng. Mahmoud — Android APK

هذا المشروع يغلّف صفحة HTML كتطبيق أندرويد باستخدام Capacitor، ويُنشئ APK مجانيًا عبر GitHub Actions.

## طريقة الاستخدام
1. ارفع كل ملفات هذا المشروع إلى مستودع GitHub جديد.
2. تأكد أن الملف الرئيسي موجود في `www/index.html`.
3. افتح تبويب **Actions** في المستودع.
4. إذا طلب GitHub تفعيل Actions، وافق على التفعيل.
5. اختر **Build Android APK** ثم **Run workflow** (أو انتظر تشغيله بعد رفع الملفات).
6. افتح عملية البناء المكتملة وانزل إلى **Artifacts**.
7. حمّل `Eng-Mahmoud-APK.zip` وفك الضغط، ثم ثبّت `app-debug.apk` على أندرويد.

## ملاحظات مهمة
- هذا APK تجريبي (debug) للتثبيت والتجربة، وليس إصدار متجر Play موقّعًا بمفتاح نشر.
- البيانات الحالية في HTML تُخزن داخل المتصفح/التطبيق محليًا. إزالة التطبيق أو مسح بياناته قد يمسح الذكريات، و`localStorage` ليس مخزنًا مناسبًا لملفات فيديو كبيرة.
- كلمة المرور الموجودة في HTML ليست حماية قوية؛ من يملك التطبيق أو يستطيع فحص بياناته قد يتجاوزها. لا تحفظ معلومات حساسة بهذا الأسلوب.
- لا تضع كلمات مرور أو مفاتيح سرية في ملفات المشروع.
